# Refinement notes

## Visual and style updates

1. **Platform map legibility**
   - Replaced the dense circular/orbit map with a five-lane executive architecture map.
   - Enlarged all labels and icons.
   - Split consumption-layer features and platform capabilities from analytics outcomes.

2. **Alignment and card readability**
   - Converted foundation components into full-width horizontal cards.
   - Added consistent collapsed and expanded states.
   - Created even-height platform capability cards and use-case cards.
   - Reduced empty white space by aligning copy, tags, and conceptual visuals to defined grids.

3. **Branding**
   - Added the provided West Monroe logo in the header and closing section.
   - Added a Parkview Health wordmark treatment with production replacement note.
   - Aligned colors to a stronger West Monroe-led palette using deep navy, blue, orange, aqua, and controlled neutral backgrounds.

4. **Tags**
   - Removed instruction-style tags such as “Expandable.”
   - Standardized tag categories: Foundation, Data, Partner, Outcome, Complexity, Consumption layer, Platform capability.

## Content updates

1. **Instructional copy removed**
   - Removed sections that described what the microsite should include.
   - Replaced them with executive-facing briefing content.

2. **Platform layer repositioned**
   - Certified Metrics, Normalized Views, Transaction Detail, and Forecast / Budget Inputs are positioned as consumption-layer features.
   - Interoperability and Reusable AI Features are positioned as platform capabilities.
   - Rapid Insights, Predictive Analytics, and AI & Workflow remain the enabled analytics outcomes.

3. **Use cases expanded**
   - Use cases now include what the use case is, conceptual solution sketches, benefits to validate, prerequisites, complexity, complexity drivers, and partner/tool relevance.

4. **Enabled analytics expanded**
   - Rapid Insights, Predictive Analytics, and AI & Workflow now have full-width sections with platform prerequisites, tools, example use cases, and conceptual UI visuals.
