# Finished-product detail spec

The finished site should feel like an executive briefing tool rather than a slide deck. Preserve the stronger contrast, West Monroe-led color system, consistent card sizing, and full-width expansion behavior.

## Visual quality requirements

- Use consistent section spacing and a maximum content width.
- Maintain strong contrast; avoid pale text on pale backgrounds.
- Keep headings in sentence case and avoid mixed title/uppercase styling inside the same content group.
- Keep cards in the same section visually consistent in size and hierarchy.
- Use white cards on defined background bands, with subtle borders and limited shadows.
- Use tag categories consistently and do not use build-instruction tags such as “Expandable.”

## Content quality requirements

- Copy should read as finished executive content, not implementation instructions.
- Explain platform features in terms of executive value.
- Use consistent description patterns across capability cards: what it is, why it matters, and what it supports.
- Use cases should include what the use case is, conceptual solution pattern, benefits to validate, prerequisites, and complexity drivers.
- Enabled analytics should each include examples, platform prerequisites, and a conceptual visual.
